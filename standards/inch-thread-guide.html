英制螺纹怎么换算？UNC、UNF、NPT、BSP 对照表

Inch Thread Conversion Guide — UNC / UNF / NPT / BSP
体系：UNC / UNF / NPT / BSPP / BSPT
牙型角：60°（美制）/ 55°（惠氏）
常用规格：1/8" ~ 1"

一、英制螺纹分几大体系

英制螺纹并不是“一种螺纹”，而是按用途和标准分成多个体系。最常见的是用于紧固的 UNC/UNF，以及用于管路密封的 NPT/BSP。判断能不能互换，先看牙型角：公制、UNC、UNF、NPT 都是 60°，BSP 与 BSW 是 55°，两者强行啮合会损坏螺纹。

体系主要标准牙型角密封性典型用途
UNC（粗牙统一螺纹）ASME B1.160°平行，不密封北美通用紧固
UNF（细牙统一螺纹）ASME B1.160°平行，不密封薄壁件、精密调整
NPT（美制锥管螺纹）ASME B1.20.160°锥面自密封北美液压、气动管路
BSPP（G，英制平行管螺纹）ISO 22855°需 O 圈/垫片欧洲、亚洲设备管路
BSPT（R，英制锥管螺纹）ISO 755°锥面自密封欧洲、亚洲管路密封

二、UNC / UNF 常用规格与公制换算表

英制规格的写法是“公称直径-每英寸牙数+系列”，例如 1/4-20 UNC 表示 1/4 英寸、每英寸 20 牙的粗牙统一螺纹。换算时：公称直径 = 英寸值 × 25.4，螺距 = 25.4 ÷ TPI。

三、NPT 与 BSP 管螺纹对照表

管螺纹的公称尺寸是“管子通径代号”，不等于实际外径。NPT 与 BSP 即使公称尺寸相同（如 1/2），牙型角与每英寸牙数也常常不同，这是现场最容易出错的地方。

NPT 与 BSPT 均为 1:16 锥度、靠锥面挤压密封；BSPP（G）为平行螺纹，必须配 O 圈或垫片，本身不密封。

四、性能等级与材料对照

  • SAE Grade 2：相当于公制 4.6 级，低碳钢，一般用途。
  • SAE Grade 5：相当于公制 8.8 级，中碳钢调质，通用机械与汽车。
  • SAE Grade 8：相当于公制 10.9 级，合金钢，重载连接。
  • A2-70 / A4-80：304 / 316 不锈钢，分别对应 700 MPa、800 MPa 抗拉强度，耐蚀场合使用。
  • 英制螺栓头部通常以“几条线”标识等级（Grade 5 为 3 条、Grade 8 为 6 条），采购时注意核对。

五、典型应用与防混用要点

  • 出口北美设备：紧固件用 UNC/UNF，液压气动接头用 NPT，按 ASME 标准验收。
  • 出口欧洲或配套欧系设备：管路优先 BSPP/BSPT，紧固件仍以公制 M 为主。
  • 图纸标注必须完整：写“1/2 管螺纹”不合格，必须写“1/2 NPT”或“1/2 BSPT”；写“M10 细牙”也必须注明螺距（如 M10×1.25）。
  • 量具匹配：55° 与 60° 螺纹分别用对应牙型角的螺纹规，不能用一种通规判断另一种体系。
