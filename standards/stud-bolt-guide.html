双头螺柱怎么选？bm=1d / 1.25d / 1.5d / 2d 四种旋入长度对照

Double End Stud Selection Guide — GB/T 897 / 898 / 899 / 900
常用规格：M5 ~ M24（标准覆盖至 M48）
性能等级：4.8 / 5.8 / 8.8 / 10.9 / 12.9 / A2-70
产品等级：A 型 / B 型，螺纹 6g

一、双头螺柱是什么，和螺栓差在哪

双头螺柱（也写作双头螺栓、螺柱）两端都带螺纹、中间是光杆，一端旋入机体（旋入端），另一端配螺母（锁紧端）。它适合被连接件太厚、不便开通孔，或需要频繁拆卸而怕损坏机体螺纹的场合。选型的核心不是“多粗多长”，而是旋入端长度 bm 取几个 d——选短了旋入螺纹不够、受力就脱扣，选长了又会顶到机体底部。

二、四个标准对应四种 bm

标准号旋入端长度 bm典型旋入基体说明
GB/T 897bm = 1d钢、锻钢、青铜等强度较高的基体最短旋入长度，机体材料强度足够时首选
GB/T 898bm = 1.25d铸铁、球墨铸铁灰铸铁强度低于钢，需加长旋入端补偿
GB/T 899bm = 1.5d强度较低的铸铁、铝合金用于机体螺纹强度不足、易滑牙的场合
GB/T 900bm = 2d铝、锌合金、塑料等软质基体最长旋入端，靠长度换取承载能力

这一组“1d / 1.25d / 1.5d / 2d”的搭配是工程界的通用经验：基体材料越软，旋入长度越长，让螺纹的剪切面积与基体的抗剪强度匹配。标准本身只规定尺寸，具体选哪个 bm 要由基体材料和受力决定。

三、常用规格的 bm 数值

bm 不是随意取的，标准按螺纹规格给出了公称值（单位 mm）：

bm 有公差，一般为公称值的 ±10% 左右（如 M10 的 1d 为 9.25~10.75mm），采购验收时应按标准表核对，而不是只看公称数。

四、A 型与 B 型怎么区分

  • A 型：旋入端螺纹收尾为倒角或短过渡，杆径较细，适合旋入通孔或对中要求不高的场合。
  • B 型：旋入端杆径 ds 约等于螺纹中径，形成一段“缩径”，可减少旋入时对机体螺纹的挤压，适合反复拆装、机体为铸铁或铝合金的场合。

标记时要写清型号与 bm，否则供货方可能按默认 A 型 1d 交付。

六、长度怎么定

双头螺柱的公称长度 l 指不含旋入端 bm 的总长（即从旋入端末端量到另一端末端），配螺母一端的有效螺纹长度约为 l - bm。设计时按“基体螺纹深度 + 被连接件总厚 + 螺母高度 + 垫圈厚度 + 2~3 扣余量”估算，再对照标准长度系列取整。

  • 螺母端露出 2~3 个螺距为宜，过短会减少有效啮合，过长白费材料且易碰伤。
  • 当 l - bm 小于 5mm 时，标准要求旋螺母一端制成倒圆端，避免端部倒角伤及螺纹。
  • 管道法兰常用等长双头螺柱（GB/T 901），两端螺纹等长，安装时不分方向。

七、安装与失效要点

  • 旋入端拧得过深：顶到盲孔底部会使螺柱受附加压应力，甚至把机体螺纹顶裂；盲孔应留 2~3 扣余量。
  • 机体螺纹滑牙：多见于铝合金、铸铁基体配 1d 旋入长度，改用 1.5d 或 2d 可显著改善。
  • 两段螺纹不同：旋入端常用过渡配合螺纹（GM、G 标记），配螺母端用普通 6g，标记时不可省略。
  • 反复拆装：每次拆装都会磨损机体螺纹，频繁维护部位优先选 B 型并适当加长 bm。
  • 扭矩不对：螺柱只承受螺母端的拧紧扭矩，旋入端应预先拧到位（可用螺纹锁固胶），否则拧螺母时整根螺柱会跟着转。

八、应用场景

  • 管道与阀门法兰：10.9/8.8 级合金钢，配 1d 或等长螺柱，按管道压力等级选。
  • 压力容器、换热器：高强度螺柱配液压拉伸器预紧，要求 10.9 级以上并做除氢。
  • 发动机缸体、变速箱：铸铁/铝合金机体，多用 1.25d~2d。
  • 模具与机床：频繁拆装的模板连接，B 型 1.25d 更耐用。
  • 腐蚀环境：A2-70 或 A4-80 不锈钢螺柱，避免与碳钢件形成电偶腐蚀。
