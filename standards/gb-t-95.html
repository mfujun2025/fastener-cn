GB/T 95 平垫圈 C级

Plain washers - Product grade C
标准号：GB/T 95-2002
发布：2002-12-05
实施：2003-06-01
规格：1.6 ~ 64 mm（C级，100HV）

一、GB/T 95 平垫圈 C级是什么

GB/T 95 规定了平垫圈 C 级的型式尺寸与技术条件，属于平垫圈中的普通系列、粗制级（C 级）：与 A 级垫圈相比，C 级垫圈尺寸公差大、表面质量要求低，配套同样粗制的 C 级螺栓/螺母使用，成本低、通用性强。硬度等级 100 HV，公称规格（螺纹大径）1.6 ~ 64 mm，与国际标准 ISO 7091 等效。

二、平垫圈系列怎么选

国标平垫圈按精度与外径分四个系列，选用时按螺栓等级与精度要求确定：

系列标准号精度/外径典型用途
平垫圈 C级GB/T 95粗制（C级），普通外径C级粗制螺栓配套、一般结构、大规格
小垫圈 A级GB/T 848精制（A级），外径最小空间受限、轻载连接
普通平垫圈 A级GB/T 97.1精制（A级），外径适中通用场合，最常用
大垫圈 A级GB/T 96.1精制（A级），外径最大软质材料、大支承面需要

四、硬度等级与适用场合

  • 100 HV 级：适用于性能等级至 6.8 级的 C 级六角头螺栓/螺钉，以及 C 级六角螺母
  • C 级垫圈与 C 级螺栓（如GB/T 5783 的粗制配套）搭配，用于一般钢结构、支架、基础连接等

五、典型应用

  • 钢结构连接：大规格粗制螺栓配套，分散支承压力
  • 设备基础与支架：设备底座、管道支架的垫平与防松配合
  • 一般机械结构：精度要求不高的板件连接、垫平调整
  • 建筑五金：膨胀螺栓、化学锚栓配套垫圈
