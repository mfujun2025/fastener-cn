船舶紧固件怎么选：盐雾腐蚀、材质与涂层

Marine Fasteners — Salt Spray, Material and Coating
典型环境：盐雾、飞溅、浸没、油污
常用材质：碳钢 / 316 / 双相钢
覆盖规格：M8～M30 粗牙
更新日期：2026-11-24

一、先按暴露区域分区

船舶紧固件怎么选，先看连接处暴露在大气区、飞溅区还是浸没区，再决定用碳钢加涂层、316 不锈钢还是双相钢。船舶紧固件的腐蚀往往从垫圈下方、螺纹缝隙和异种金属接触处开始，单看螺栓外观很难判断；材料、涂层、隔离和装配要一起设计。

区域环境特点推荐方案主要风险
大气区（上层建筑、栏杆）盐雾、雨水、紫外316/A4-70，或 8.8 级 + 锌铝涂层/热镀锌 + 面漆点蚀、涂层划伤、缝隙腐蚀
飞溅区（甲板、舷侧）干湿交替、氯离子浓缩316L/A4-70、2205 双相钢，重防腐体系缝隙腐蚀、应力腐蚀
浸没区（压载舱、水下）连续海水、低氧、流速变化316L、2205/2507 双相钢、铜合金点蚀、电偶腐蚀、冲刷
机舱、货舱温度、油污、磨损10.9 级 + 锌铝/磷化；非结构可用 304松动、油污老化、拆装咬死

把“船用”理解成“全船都用 316”并不准确。316 在飞溅区和低氧缝隙里仍可能点蚀；反过来，大气区和非关键内装件用碳钢加合适涂层，往往更经济。关键结构连接还要满足船级社规范和图样要求。

二、材质怎么选：碳钢、不锈钢与双相钢

船用紧固件的材料选择，本质是耐蚀性、强度、成本和可维护性的平衡。碳钢加涂层适合大气区和结构件；304 适合保护较好的内装环境；316 适合外露大气区和有维护的飞溅区；双相钢适合更苛刻的浸没和关键结构。

材料典型等级/牌号耐蚀特点适用与限制
碳钢 + 热浸镀锌8.8 / 10.9厚锌层，大气区重防腐船体、甲板结构；飞溅/浸没不推荐，需预留螺纹间隙
304（A2）A2-70大气环境尚可，成本较低仅限保护较好的内装；飞溅区易点蚀
316（A4）A4-70 / A4-80含 2%～3% 钼，抗氯离子点蚀更好外露大气区、甲板栏杆；垫圈下仍可能缝隙腐蚀
316LA4-70低碳，焊接后抗晶间腐蚀更好压载舱、管路、焊接结构；强度需校核
双相不锈钢2205 / 2507高强度 + 耐氯离子腐蚀飞溅区、浸没区、关键结构；加工和焊接要求高

304 和 316 差在哪里

316 的铬、镍含量与 304 接近，但额外加入 2%～3% 的钼。钼能稳定氯离子环境下的钝化膜，提高抗点蚀和缝隙腐蚀能力。304 不是“不能用”，而是更适合保护较好的内装、机柜和非外露件；外露甲板、栏杆和飞溅区应优先 316 或更高级别。

三、强度等级与 A4-70 性能

碳钢螺栓按 8.8、10.9、12.9 分级，不锈钢螺栓按 ISO 3506-1 的 A2-70、A4-70、A4-80 等标记。两组数字不能直接互换：A4-70 的抗拉强度约 700 MPa，明显低于 10.9 级的 1 040 MPa，不能用同规格不锈钢简单替代高强度碳钢。

等级抗拉强度 Rm屈服/0.2% 非比例延伸强度断后伸长率典型用途
8.8≥800 MPa≥640 MPa≥12%一般结构、内装、支架
10.9≥1 040 MPa≥940 MPa≥9%甲板机械、机舱、重载连接
A2-70≥700 MPa≥450 MPa≥0.4d304 内装、非外露件
A4-70≥700 MPa≥450 MPa≥0.4d316 外露大气区、栏杆、甲板附件
A4-80≥800 MPa≥600 MPa≥0.3d需要更高承载的 316 连接

表中不锈钢性能按 ISO 3506-1:2020 整理，伸长率以“倍直径”表示，不是百分比。A4-80 通过冷作硬化提高强度，韧性余量比 A4-70 小；承受冲击或低温工况时，要单独评估，不能只看强度数字。

四、常用规格与预紧力

船舶和海洋工程常用 M8～M30 粗牙螺栓。下表按 10.9 级保证载荷 830 MPa 的 75% 估算预紧力，方便选型和现场核对。实际扭矩要按连接副实测 K 值计算；大规格连接常用液压拉伸或加热拧紧，不能只靠扭矩扳手。

规格螺距 P (mm)As (mm²)10.9 级 75% 预紧力典型部位常见方案
M81.2536.622.8 kN栏杆、附件、内装支架A4-70 / 8.8+锌铝
M101.558.036.1 kN甲板附件、机舱管系A4-70 / 10.9+锌铝
M121.7584.352.5 kN栏杆底座、设备支架A4-70 / 10.9+锌铝
M162.015797.7 kN甲板机械、舱口盖10.9+热镀锌/锌铝
M202.5245152.5 kN船体结构、系泊设备10.9+重防腐 / 双相钢
M243.0353219.7 kN主机座、大型结构10.9 / 双相钢

表中的预紧力是估算值，不替代设计计算。不锈钢螺栓的弹性模量和碳钢不同，温度变化下的预紧力损失也不同；海水温度、船体振动和连接副热膨胀都会影响残余预紧力。关键连接应给出预紧力范围、拧紧方法和复紧周期。

五、涂层与防腐体系

船用紧固件的涂层要同时满足防腐、螺纹通规和装配摩擦要求。热浸镀锌适合大气区和船体结构；锌铝涂层适合机舱和上建外露件；锌镍合金适合高耐蚀要求；不锈钢则靠钝化膜，不需要额外涂层，但要避免划伤和铁污染。

涂层/防护典型膜厚耐蚀特点适用与限制
热浸镀锌45～85 μm厚锌层，大气区长效防腐船体、甲板结构；需预留螺纹间隙，飞溅/浸没不推荐
锌铝涂层5～12 μm中性盐雾可达 720 h 量级，无氢脆机舱、上建、设备；K 值按涂层实测
锌镍合金电镀5～15 μm耐蚀性高，适合盐雾环境10.9 级以上必须去氢，废水处理要求高
环氧/聚氨酯面漆按体系与镀层形成复合防腐按 ISO 12944 环境等级设计；螺纹部位要保护
不锈钢钝化—依靠铬氧化物钝化膜焊后/加工后酸洗钝化，避免铁离子污染和划伤

盐雾试验小时数不等于实际使用寿命。飞溅区的干湿交替、缝隙里的低氧环境和机械划伤，都比标准盐雾更苛刻。涂层螺栓在装配时被扳手划伤、螺纹被泥沙磨伤，都会成为早期腐蚀起点；关键部位应规定涂层修补和安装后检查。

六、电偶腐蚀与隔离

船舶紧固件最常见的隐蔽问题不是螺栓本身锈，而是螺栓把两种电位不同的金属连在一起，让较活泼的一侧加速腐蚀。海水是良导体，电偶腐蚀一旦形成，往往在垫圈下方、孔壁和螺纹根部开始，外观检查容易漏掉。

接触组合腐蚀风险常用措施
碳钢螺栓 + 不锈钢结构碳钢作为阳极加速腐蚀改用不锈钢螺栓，或绝缘垫/套管隔离，避免小阳极大阴极
不锈钢螺栓 + 铝合金铝孔和铝板腐蚀绝缘垫圈、衬套、密封胶，切断导电通路
铜合金 + 碳钢碳钢腐蚀隔离、涂层、避免海水滞留
不锈钢螺栓 + 碳钢甲板碳钢甲板局部腐蚀绝缘垫、涂层、密封；定期检查垫圈下方
不锈钢螺栓 + 不锈钢螺母咬死，不是电偶腐蚀防咬合剂、控制表面硬度、避免高速拧紧

切断电偶回路比单纯加厚涂层更有效。绝缘垫圈、绝缘套管和密封胶要能承受装配压缩和老化；如果垫圈被压破、套管缺失，海水进入后仍会形成回路。设计时还要避免积水凹槽和盲孔，给甲板连接留排水路径。

七、防松、咬死与拆装

船舶振动、温度循环和长期预紧力松弛会叠加。防松件只能保住已有预紧力，不能弥补预紧力不足；不锈钢螺栓的咬死则更多与摩擦、冷焊和表面粗糙度有关，和防松是两个问题。

问题常用方案注意点
振动松动全金属锁紧螺母、法兰面螺栓、预涂螺纹胶尼龙锁紧件受温度限制；螺纹胶多为一次性
不锈钢咬死防咬合剂、不同硬度配对、低速拧紧不要干拧；避免重复使用已拉毛的螺纹
拆卸困难渗透油、加热、专用扳手加热温度受涂层和材料限制，不能烧坏锌层
薄板压陷加大垫圈、法兰面螺栓、降低预紧力校核被连接件承压能力，不能只加厚垫圈
反复拆装可重复使用的锁紧螺母、螺纹衬套每次拆装检查螺纹和涂层，必要时更换

甲板和舷侧连接要预留维护空间。很多腐蚀和松动不是选型错误，而是垫圈下方无法检查、积水排不掉、拆装时把涂层破坏。设计阶段把可检查性和可更换性考虑进去，比后期加大螺栓规格更有效。

八、装配与检验

船用紧固件的装配质量，取决于预紧力控制、螺纹状态和防腐完整性。关键连接应保留材料证明、涂层报告、扭矩记录和检验记录，便于船级社、船东和后续维护追溯。

  1. 核对材质与证书：螺栓、螺母、垫圈牌号和等级匹配；关键件查材质证明和炉批号。
  2. 检查螺纹与涂层：螺纹无毛刺、无铁屑、无严重划伤；热镀锌件通规检查。
  3. 控制摩擦：同一连接副使用同一润滑/防咬合体系，涂覆位置和用量固定。
  4. 校准工具：扭矩扳手、液压拉伸器按周期校准；记录压力-扭矩/伸长量关系。
  5. 分步拧紧：按对称顺序分 2～3 次到目标；大规格优先液压拉伸或加热拧紧。
  6. 检查啮合：拧紧后螺杆伸出螺母 2～3 个螺距，螺纹完整啮合。
  7. 防腐修补：装配划伤处按涂层体系修补；不锈钢件避免碳钢铁污染。
  8. 记录与复查：记录批次、K 值、预紧力、操作者和日期；按维护周期复查。

盐雾试验可按 ISO 9227 或 GB/T 10125 进行，热浸镀锌可按 ISO 1461 或 GB/T 13912 检查，涂层体系可按 ISO 12944 的环境等级设计。涉及船级社规范时，以 CCS、DNV、ABS、LR、BV 等现行规则和批准文件为准。
