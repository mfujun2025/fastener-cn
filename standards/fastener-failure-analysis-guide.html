紧固件失效怎么查？七类失效模式、断口特征与排查顺序

Fastener Failure Analysis — Failure Modes, Fracture Features and Root-Cause Workflow
常见模式：7 类
关键判据：断口形貌 + 失效时间
相关试验：硬度、金相、氢含量

一、先分模式，再谈责任

紧固件失效分析的第一步不是做试验，而是判断失效模式。同样是一根螺栓断了，过载断裂、疲劳断裂和氢脆延迟断裂的原因、责任归属和预防措施完全不同；模式判错，后面做再多试验也会跑偏。现场能拿到的三条线索最值钱：断口形貌、从装配到失效的时间、以及断在什么位置（头下圆角、第一扣螺纹、杆部或螺纹收尾）。

三、断口怎么读

断口是失效分析的核心证据，不要用手直接摸或用砂纸打磨。宏观先看三件事：是否有颈缩等塑性变形、断口是否平齐、断裂位置是否集中在同一扣螺纹。微观再看形貌：韧窝说明延性过载；解理或沿晶说明脆性；疲劳海滩纹说明循环载荷；沿晶且晶界有析出或腐蚀产物，则指向氢脆或应力腐蚀。多数现场失效是混合模式——先疲劳起裂、再瞬断——报告里要写清主因与诱因。

取样时保留完整断口，用保鲜膜或防锈油保护，避免二次锈蚀；同一批零件应同时抽取未失效件做对比，测量硬度、镀层厚度与螺纹尺寸，判断是否存在批次性偏差。

四、从装配找原因

大量“螺栓强度不够”的结论，最后都落在装配上。预紧力不足时，螺栓承受的交变应力幅变大，疲劳寿命急剧下降；预紧力过大或扭矩法控制粗糙时，又容易在拧紧瞬间过载。扭矩法受摩擦系数影响很大，同一扭矩下不同润滑状态的实际预紧力可能相差很大，因此关键连接应控制摩擦系数、抽检扭矩-夹紧力关系，重要部位改用转角法或屈服点法。

还要核对支承面：支承面被压溃、被连接件蠕变或垫圈压平，都会让夹紧力在服役中缓慢损失，看起来“没松”，实际预紧力已经不够。软质材料（铝、塑料）应加法兰面或加大垫圈，不能只靠提高扭矩。

五、氢脆：高强度件的高发风险

氢脆的典型特征是“装配时没事，几小时到几天后突然断”，断口平齐、无颈缩。氢来自电镀、酸洗、磷化或服役环境的阴极保护。经验门槛是硬度约 39HRC 以上风险显著上升，10.9 级及以上螺栓、弹性垫圈、自攻螺钉都属于敏感件。预防手段是镀前避免强酸过度侵蚀、镀后按规定去氢（一般 200℃ 左右保温数小时，具体按工艺文件），并优先选用达克罗、机械镀锌等低氢工艺。发生延迟断裂时，先查硬度与去氢记录，不要先怀疑材料。

六、排查六步

  • 第一步 保护现场：收集断件、同批未用件、装配记录与工况参数，断口防锈防碰。
  • 第二步 定位置：统计断点是否集中在头下圆角、第一扣螺纹、螺纹收尾或杆部，位置本身就指向成因。
  • 第三步 看宏观：判断有无塑性变形、有无锈蚀、有无咬合拉毛，先排除装配与腐蚀因素。
  • 第四步 做试验：按需做硬度、金相、镀层厚度、氢含量、拉力或保证载荷试验，用数据支撑模式判断。
  • 第五步 回溯批次：查材料炉批、热处理记录、表面处理记录与验收报告，确认是否批次性问题。
  • 第六步 定措施：针对主因改设计、改装配或改表面处理，并用小批量验证后再推广。

七、常见误区

  • 断在螺纹就判材料差：第一扣螺纹本就是应力最高处，过载与疲劳都常断在这里。
  • 看到锈就判腐蚀失效：断后暴露的断面同样会生锈，要区分服役期腐蚀与事后锈蚀。
  • 只提高等级不加预紧：把 8.8 换成 10.9 却不提高预紧力，疲劳问题依旧。
  • 用加大扭矩解决松动：扭矩过大先压溃支承面，反而加速夹紧力损失。
  • 忽略去氢时效：镀后放置几天才断裂，容易被误判为“使用中过载”。
  • 单件分析就下结论：没有同批对比件，无法判断是偶发缺陷还是批次性问题。

八、应用场景

  • 主机厂装配线断裂：优先区分过载与氢脆，核查扭矩曲线与镀后去氢。
  • 风电、桥梁等结构连接：长期交变载荷，重点查疲劳与预紧力损失。
  • 户外与沿海设备：锈蚀、应力腐蚀与镀层失效为主，配合盐雾数据判断。
  • 家电与钣金件滑牙：多与螺纹精度、板厚和拧紧参数有关。
  • 售后批量退货：按批次做对比试验，区分设计问题与制造波动。
