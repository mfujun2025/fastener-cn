组合螺钉怎么选？GB/T 9074 平垫、弹垫组合与规格对照

SEMS Screws — Screw and Washer Assemblies per GB/T 9074
标准：GB/T 9074 系列
规格范围：M2～M10（9074.1-2018）
常见等级：4.8 级，镀锌钝化

一、组合螺钉是什么

组合螺钉是把螺钉与平垫圈、弹簧垫圈在出厂时组装成一体的紧固件，也叫 SEMS 螺钉、组合件螺钉、三组合。标准要求垫圈应能自由转动而不脱落：装配时不会掉垫圈，工人也不必再单独取放垫圈。它解决的是“装配效率与漏装”问题，而不是“提高强度”问题——组合件的螺钉本体仍是普通 4.8 级螺钉，不能因为多了垫圈就当作高强螺栓使用。

二、四种常见组合，先看标准号

标准组合内容典型头型适用场合
GB/T 9074.1十字槽盘头螺钉 + 平垫圈盘头（H 型十字槽）一般金属件、需要增大承压面
GB/T 9074.2十字槽盘头螺钉 + 弹簧垫圈盘头有轻微振动、需补充防松
GB/T 9074.4十字槽盘头螺钉 + 弹簧垫圈 + 平垫圈盘头（三组合）既要防松又要保护表面
GB/T 9074.13十字槽凹穴六角头螺栓 + 弹簧垫圈 + 平垫圈六角头凹穴需要较大预紧力、可上套筒

采购时只写“组合螺钉 M6×20”不够，必须写清标准号、头型、垫圈组合与性能等级，否则供应商可能按不同系列发货。标记方法按 GB/T 1237，例如“螺钉组合件 GB/T 9074.1 M6×20”。

四、长度怎么算，最容易出错

组合件的公称长度 l 指螺钉本身的长度，不含垫圈厚度。装配后垫圈会占掉 h 的高度，实际可用的螺纹长度变短。选长度时应按“被连接件总厚度 + 垫圈厚度 h + 旋合长度”计算，再向上取标准长度；如果按普通螺钉的经验直接选同长度，往往会出现旋合牙数不足、拧不紧或顶到盲孔底部。

以 M6 三组合、被连接件总厚 12mm、垫圈总厚约 3.2mm、需要 8mm 旋合为例，所需螺钉长度约 12+3.2+8=23.2mm，应选 l=25mm 的规格，并确认螺纹长度能覆盖旋合段。薄板件还要核对是否全螺纹，避免螺纹段不够。

五、性能等级与防松边界

GB/T 9074 组合件的螺钉一般按 4.8 级供货，抗拉强度约 400MPa 级，适合机箱、支架、家电、一般机械外壳等轻中载荷连接。它不是 8.8 级、10.9 级高强螺栓的替代品：需要高预紧力的法兰、传动件、承力结构，应选高强度螺栓并单独配垫圈。弹簧垫圈的防松作用主要是补偿预紧松弛和抵抗轻微振动，遇到冲击、交变横向载荷或安全相关部位，应改用锁紧螺母、法兰面螺母、螺纹锁固胶或双螺母等方案。

六、产线与装配要点

  • 送料适配：盘头组合件适合振动料斗与自动送钉机，沉头组合件易卡料，自动线优先盘头。
  • 垫圈方向：平垫靠被连接件、弹垫靠头部，三组合顺序不能装反，否则防松和承压都失效。
  • 扭矩按 4.8 级：不要套用 8.8 级扭矩表，过大扭矩会压溃垫圈或滑牙。
  • 拆卸后检查：垫圈变形、弹垫压平或丢失的组合件应整套更换，不要只补一个垫圈。
  • 表面处理匹配：镀锌钝化适合室内；潮湿、户外或沿海环境选不锈钢或达克罗，并注意氢脆风险。

七、选型步骤

  • 第一步 定组合：只需增大承压面选 9074.1；需补充防松选 9074.2 或 9074.4；要上套筒、预紧较大选 9074.13。
  • 第二步 定规格：按螺纹公称直径与螺距选 M3～M10，核对头径能否放入安装孔位。
  • 第三步 算长度：被连接件厚度 + 垫圈厚 + 旋合长度，向上取标准 l。
  • 第四步 核强度：按 4.8 级校核，载荷超过范围改用高强螺栓方案。
  • 第五步 定表面：按环境选镀锌、不锈钢或达克罗。
  • 第六步 写标记：标准号 + 规格 + 长度 + 材料/表面，按 GB/T 1237 完整标注。

八、常见误区

  • 把组合件当高强螺栓：多一个垫圈不会提高强度等级，4.8 级就是 4.8 级。
  • 长度按光杆算：忽略垫圈厚度，装配后旋合不足。
  • 弹垫万能防松：高频冲击、横向交变载荷下弹垫效果有限，需换防松结构。
  • 只写“三组合”不写标准：9074.4 与 9074.13 头型不同，容易发错货。
  • 自动线用沉头组合：沉头对中性差、易卡料，产线效率反而下降。
  • 重复使用拆卸件：垫圈压平后失去弹性，防松能力下降。

九、应用场景

  • 机箱、机柜、控制盒：M3～M5 盘头组合，装配快、外观整齐。
  • 家电与办公设备：M4～M6 三组合，减少产线零件种类。
  • 电机、泵体、支架：M6～M10，六角凹穴组合可上套筒、预紧更均匀。
  • 汽车零部件与农机：中小规格组合件用于非承力覆盖件，承力部位另选高强螺栓。
  • 出口设备：按客户要求选不锈钢组合件，避免镀锌层在潮湿环境失效。
