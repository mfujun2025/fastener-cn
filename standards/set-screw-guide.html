紧定螺钉怎么选？八种端型、槽型与 14H-45H 硬度等级对照

Set Screw Selection Guide — GB/T 71 / 73 / 74 / 75 / 77 / 78 / 79 / 80
常用规格：M1.6 ~ M24
硬度等级：14H / 22H / 33H / 45H
产品等级：A 级，螺纹 6g

一、紧定螺钉是什么

紧定螺钉俗称“顶丝”“止付螺丝”，是没有头部的一类螺钉，靠末端顶紧另一零件来固定相对位置。它不承受拉力，主要承受压紧力和扭矩，所以标准不按抗拉强度分级，而按硬度等级分级（GB/T 3098.3）。选型要同时定三件事：末端形状（端型）、扳拧方式（槽型）、硬度等级。

二、端型怎么选

端型开槽标准内六角标准受力特点与适用场合
锥端GB/T 71GB/T 78端部呈锥形，可压入被顶零件形成定位坑，定位可靠；适合硬度较低的轴、需防轴向滑移的场合，会留下压痕

三、槽型怎么选

  • 开槽（一字）：成本低，但拧紧力矩小，螺丝刀容易打滑，适合小规格、低扭矩场合。
  • 内六角：可承受更大扭矩，扳手不易打滑，是 M4 以上紧定螺钉的主流选择；缺点是内六角容易积屑。
  • 方头：可用开口扳手或套筒，扭矩最大，适合重载，但头部突出。

同样规格下，内六角能给的拧紧力矩明显高于开槽，因此需要可靠防松时优先选内六角。

四、硬度等级 14H / 22H / 33H / 45H

等级代号中的数字是最低维氏硬度的 1/10，H 表示硬度。四个等级并非都适用于所有槽型：内六角紧定螺钉通常只做 33H 和 45H，14H、22H 主要用于开槽和方头产品。

45H 级不允许有全脱碳层，采购时若用于受力关键部位，应在技术协议中写明脱碳要求和保证扭矩试验。

五、45H 内六角紧定螺钉的保证扭矩

保证扭矩是螺钉在不断裂、不裂开、不滑牙的前提下能承受的扭矩，是紧定螺钉最重要的验收指标：

实际装配扭矩建议取保证扭矩的 60%~80%，既保证防松又不至于把内六角拧坏或把轴面顶出过深凹坑。

六、常见失效与安装要点

  • 内六角滑方：扭矩超过保证值、扳手磨损或内六角深度不足，都会导致扳手打滑。
  • 顶伤配合面：锥端、凹端在硬度低的轴上会压出深坑，拆卸后影响轴的同轴度；精密轴优先用平端并加垫片。
  • 振动松脱：紧定螺钉没有弹性，振动工况应加防松胶、双螺钉对顶，或改用带尼龙嵌件的防松结构。
  • 薄壁管压扁：薄壁件用长圆柱端插入孔中，而不是直接用锥端顶在管壁上。
  • 未对中：先在轴上钻定位孔再拧紧，可显著提高传递扭矩的能力。

七、应用场景

  • 传动件固定：皮带轮、链轮、联轴器、齿轮与轴的周向固定，多用内六角平端或圆柱端 45H。
  • 模具与夹具：镶件、导柱、定位块的固定，多用内六角平端 45H 或凹端。
  • 仪器与电子：旋钮、面板、小型轴承的定位，多用开槽 14H/22H 小规格。
  • 管件与轴套：薄壁管、轴套的固定，用长圆柱端，配防松胶。
