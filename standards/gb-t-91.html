GB/T 91 开口销

Split cotter pins
标准号：GB/T 91
发布：2000-09-26
实施：2001-02-01
对应：ISO 1234 / DIN 94
规格：公称直径 0.6 ~ 20 mm

一、适用范围

GB/T 91 规定了开口销的型式尺寸、技术条件和标记方法。开口销是一种弯曲成半圆形的销子，两脚可张开，常用于穿过带孔螺栓、带槽螺母或销轴上的销孔，将两脚分开折弯，防止连接件松动脱落。开口销是最简单、最可靠的机械防松方式之一，广泛应用于汽车、农机、铁路、建筑机械、电气设备等领域。

二、防松原理

  1. 开口销穿过带孔螺栓（如 GB/T 37 六角头带孔螺栓）或带槽螺母（如 GB/T 6178 开槽螺母）的销孔
  2. 将开口销的两个脚分别向两侧掰开，弯折约60°~90°
  3. 两脚卡在螺母侧面或螺栓头部，阻止螺母回转
  4. 即使受到强烈振动，螺母也无法从螺栓上旋出

四、材料与表面处理

  • 材料：低碳钢（Q215、Q235）、铜合金、不锈钢（1Cr18Ni9Ti等）
  • 表面处理：镀锌（最常用）、发黑、磷化、镀镍、不锈钢本色
  • 性能要求：弯曲试验、剪切试验合格，无裂纹、毛刺

六、安装方法

  1. 将开口销插入销孔，确保两脚露出足够长度
  2. 用钳子将两个脚分别向两侧弯折
  3. 弯折角度约60°~90°，一脚弯向螺栓头部，一脚弯向螺母侧面
  4. 弯折后两脚应紧贴被连接件，防止刮伤

七、使用注意事项

  • 开口销只能使用一次，拆下后必须更换新件
  • 规格应略小于销孔直径（一般小0.1~0.3mm）
  • 腐蚀环境下选用不锈钢开口销
  • 严禁以铁丝、铁钉代替开口销

八、典型应用

  • 汽车底盘：转向拉杆球头、悬挂销轴的防松
  • 农机具：拖拉机悬挂装置、犁具的连接
  • 铁路车辆：转向架、制动装置的连接防松
  • 工程机械：销轴连接部位（挖掘机大臂销等）
  • 电气设备：开关机构、传动机构的定位防松
